Habit-Tracker


Sovelluksen toiminnot:

- Käyttäjä pystyy luomaan tunnuksen ja kirjautumaan sisään sovellukseen.
- Käyttäjä pystyy lisäämään tapoja sekä muokkaamaan ja poistamaan lisäämiään tapoja. Myös jo luotoihin tapoihin muut käyttäjät voivat liittyä.
- Käyttäjä näkee sekä itse lisäämänsä että muiden käyttäjien lisäämät tavat.
- Käyttäjä pystyy etsimään tapoja nimen perusteella
- Käyttäjäsivu näyttää käyttäjän lisäämien reittien ja retkiraporttien määrät sekä listat käyttäjän lisäämistä reiteistä ja retkiraporteista.
- Luokittelujen vaihtoehdot on tallennettu tietokantaan.
- Käyttäjä pystyy lisäämään omiin ja muiden käyttäjien tapoihin muistiinpanot ja motivaatiorepliikit.
- Käyttäjä pystyy poistamaan oman tavan.
- Sovelluksessa on käyttäjäsivut, jotka näyttävät tilastoja eli montako päivää putkeen käyttäjä on suorittanut tapoja. Myös käyttäjän lisäämät tavat näkyy.
- Käyttäjä pystyy valitsemaan ilmoitukselle yhden tai useamman luokittelun: toistuvuuden määrä per viikko ja osaston (urheilu, hyvinvointi, terveys jne.)
